# Finz AI-Native Financial Review Challenge

MVP implementation for the Finz Software Engineering Internship challenge.

## Architecture
- FastAPI API + lightweight single-page UI
- SQLAlchemy database (SQLite locally; PostgreSQL via DATABASE_URL in production)
- Pandas/OpenPyXL ingestion
- Deterministic chart-of-accounts classification for obvious transactions
- Human review/correction for ambiguous/non-P&L transactions
- Deterministic monthly P&L and variance calculations
- Optional Groq LLM for conversational investigation; financial numbers are not generated by the LLM

## Run
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
Open http://127.0.0.1:8000

## Environment
Copy `.env.example` to `.env` and set `GROQ_API_KEY` for the AI fallback. The app's deterministic financial endpoints work without an API key.

## Challenge principles
1. Deterministic computation for financial totals.
2. AI for interpretation and investigation.
3. Human-in-the-loop for accounting judgment.
4. Every material answer should be traceable to underlying transactions.

## Demo flow
1. Upload the provided XLSX.
2. Review flagged transactions.
3. Correct at least one classification.
4. Inspect monthly P&L.
5. Inspect February → March variance.
6. Ask the analyst two questions.
